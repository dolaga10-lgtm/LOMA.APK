# تطبيق شركة الحافظ للمطابخ والألومنيوم والواجهات الزجاجية

تطبيق أندرويد متكامل يجمع بين منظومة الورشة الذكية الهندسية كاملة وبين هوية وتراخيص وسيرفر **شركة الحافظ** (خبرة منذ 1980).

---

## أبرز التحديثات المكتملة في هذا الإصدار:

1. **تحديث مسميات الشركات وضبط أشكال مقاطع الـ SVG الحقيقية لكل جزء:**
   - استبدال قطاع السعد بـ **قطاعات السلام (PS)**: `PS 9600` جرار كبير، `PS 6600` جرار صغير، `PS 5600` مفصلي كبير، `PS 4800` مفصلي صغير.
   - استبدال الماكينات الشارقة بـ **قطاعات الشريف**: جامبو 100 جرار (`JamBo100`)، تانجو 60 (`Tango60`)، تندو 120 (`TenDu120`)، تيمبو 84 (`TemBo84`)، سوناتا 45 مفصلي (`Sonata45`)، نانو 50 اقتصادي (`Nano50`).
   - ضبط شكل المقطع (SVG) أمام كل جزء في جميع القطاعات بحيث يظهر أمام الدرفة شكل الدرفة الحقيقي، وأمام الحلق شكل الحلق، وأمام السكينة شكل السكينة، وأمام السؤاس والباكتة أشكالها الصحيحة.

2. **إضافة نظام الباندا (Panda System) في الشباك المفصلي بتسعير (المتر × 1.5):**
   - عند اختيار نظام **مفصلي**، يظهر خيار تفعيل **نظام الباندا** أسفل خيارات الضلف.
   - عند تفعيل الباندا، يُحسب سعر المتر بمتر ونصف تلقائياً (`× 1.5`، مثلاً إذا كان المتر العادي بـ 1000 جنيه يصبح بـ 1500 جنيه مع الباندا)، مع إدراج قطاعات ضلفة الباندا في حساب الطلبية والرسم التفاعلي.

3. **ضبط تركيب الشفاط داخل الثوابت فقط (وفي جزء واحد عند تقسيم الثابت):**
   - يتم وضع الشفاط داخل **الثوابت** (العلوي / السفلي / اليمين / الشمال) وليس داخل الدرفة المتحركة.
   - إذا كان الثابت مقسماً إلى عدة أجزاء (مقسوم 2 أو 3 أو 4)، يتم وضع الشفاط في **جزء واحد محدد** من أجزاء الثابت.

4. **اختيار طبقتي الزجاج الدابل + إضافة سعر السبيسر من قائمة التسعير:**
   - عند اختيار **زجاج دابل**، يفتح خيار تحديد **نوع الطبقة الأولى** و**نوع الطبقة الثانية** من قائمة تسعير الزجاج، ويُضاف عليهما **سعر السبيسر** المحدد في قائمة التسعير تلقائياً.

5. **دقة مقاسات وعدد قطع الزجاج في حساب الطلبية والـ PDF لكل قطاع:**
   - إخراج مقاسات الزجاج الصافية لكل قطاع بمعادلاته الخاصة من المشروع المماثل:
     - **درفة واحدة** = قطعة زجاج واحدة
     - **درفتين** = قطعتين زجاج
     - **4 درف** = 4 قطع زجاج
   - بالإضافة إلى حساب زجاج **جميع الثوابت** (فوق / تحت / يمين / شمال) بالعدد والمقاس الصافي لكل قطاع في شاشة حساب الطلبية وملف الـ PDF.
